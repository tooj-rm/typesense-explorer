# Typesense Explorer (Beta)

Typesense Explorer is a lightweight, web-based admin and debugging interface for interacting with
a Typesense search cluster. It provides an intuitive UI to inspect, query, 
and manage your Typesense collections without needing to write API calls manually.

# Docker Usage
Run Typesense Explorer quickly using Docker:
```bash
docker run --rm -d -p 3001:3000 toojrm/typesense-explorer:beta
```

# 🚀 Features
- 📚 Collection Browser
- 📊 Document Viewer
- 🌐 Modern Web UI – Clean, interface designed for developer productivity.
